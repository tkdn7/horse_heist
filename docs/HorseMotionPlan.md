# 말 달리기 모션 개선 제안

## 이번에 적용한 범위

- 기존 말 모델 위에 추가하던 막대 형태의 상체 다리·하체 다리·발굽 생성 코드를 제거했다.
- 원본 말 템플릿과 실제로 보이는 메시·Union은 그대로 사용한다. 모델 안에 원래부터 숨겨져 있는 관절용 부품도 숨김 상태를 유지한다.
- 네 다리의 움직임 시점을 다르게 하고, 속도가 바뀌어도 보행 주기가 갑자기 튀지 않는 기존 방식으로 움직인다.
- 납작하게 퍼지는 슬라이딩과 사람처럼 서는 점프는 유지한다.

현재 외형을 유지한 채 관절 중심으로 다리를 회전할 수는 있지만, 하나로 굳어 있는 다리 모양을 실제 무릎처럼 구부릴 수는 없다. 이번 수정이 사실적인 관절 애니메이션의 완성을 뜻하지는 않는다.

## 추천하는 다음 작업

**먼저 말 한 종류를 스키닝된 메시로 제작해 움직임을 검증하고, 같은 골격을 나머지 말에 적용한다.** 블록 도형을 덧붙이는 대신 말의 표면 자체가 관절을 따라 구부러져야 한다.

1. Blender에서 기존 말과 비슷한 외형의 작업용 메시를 마련하고, 몸통·목·머리·네 다리·발굽에 골격을 만든다. 원본 Studio 템플릿은 별도로 보존한다.
2. 앞다리의 손목과 뒷다리의 무릎·비절이 서로 다른 방향과 범위로 접히도록 배치한다. 관절 주변의 표면이 찌그러지지 않도록 스킨 가중치를 조정한다.
3. 측면·정면의 실제 말 질주 영상을 기준으로 접지, 밀어내기, 다리 회수, 공중 구간을 키프레임으로 만든다. 네 다리가 같은 순간에 움직이지 않게 하고 몸통·목의 움직임도 함께 조정한다.
4. 달리기 애니메이션 재생 속도를 실제 이동 속도에 맞춘다. 처음에는 고정된 평지에서 발 미끄러짐과 반복 구간 연결을 검증한다.
5. 기본 질주가 만족스러워진 뒤 착지 보정과 지면 높이 보정을 추가한다. 지금의 과장된 점프·슬라이딩은 별도 애니메이션으로 제작하고 전환을 부드럽게 섞는다.

Roblox는 내부 Bone과 스킨 가중치를 가진 메시를 지원한다. 제작 방법은 [Rigging and skinning](https://create.roblox.com/docs/art/modeling/rigging)과 [Blender에서 메시 스키닝하기](https://create.roblox.com/docs/art/modeling/skin-a-simple-mesh)를 기준으로 진행하면 된다.

기존 `VisualRig`는 각 부품의 CFrame을 직접 지정한다. 따라서 새 메시에는 Bone/AnimationController를 사용하는 렌더링 경로를 추가해야 한다. 새 모델을 그대로 넣기만 해서는 관절 애니메이션이 자동으로 작동하지 않는다. 서버의 추격·충돌·소유권 판정은 이 작업과 분리해 그대로 사용할 수 있다.

완료 기준은 모든 방향에서 관절이 분리되지 않을 것, 속도 변경 시 발이 튀지 않을 것, 기수가 안장에서 뜨지 않을 것, 점프·슬라이딩 후 원래 형태로 복귀할 것이다.

## 이번 추격 조정과 포기 규칙

- 플레이어 간 훔치기의 기본 간격은 28 studs이다. UI에서는 기존 표기를 따라 m로 표시한다.
- 당근을 놓치면 2, 장애물에 충돌하면 6만큼 불리해진다. 도둑의 실수는 간격을 줄이고, 직접 추격하는 주인의 실수는 간격을 늘린다.
- 당근 미스로 인한 영구 감속은 없다. 실수 후 정상 주행하면 그 간격을 유지한다. 속도 증가 능력을 사용하는 동안에는 능력의 효과로 간격이 바뀔 수 있다.
- NPC 대리 추격에도 같은 유한 거리 패널티를 적용한다. 농장 안에서 순찰하는 경비견 속도는 이번 변경 대상이 아니다.
- 주인이 포기하면 도둑에게 소유권을 이전하고, 도둑이 포기하면 원래 주인이 유지한다. 알림·대기·카운트다운·달리는 중에 가능하며 NPC에게 맡긴 주인도 포기할 수 있다.
- 서버가 참가자와 현재 사건 ID를 확인한 뒤 한 번만 결과를 확정한다. 소유권 저장이 실패하면 성공으로 표시하지 않는다.
